# Changelog

## Unreleased

The first version: places and things, search, QR labels, tags, custom fields, documents, maintenance with reminders and API tokens for other apps. See [PLAN.md](PLAN.md).

- Maintenance can repeat every so many weeks or months. Marking it done asks the day and cost and adds the next one; an entry done before keeps that date.
- The Maintenance page lists everything scheduled in the household, by when it's due, and what was done in the last year.
- Two kinds can't have the same name, built-in ones in any language included.
- Deleting a kind that things are of moves them to another kind, which also merges two kinds named alike.
